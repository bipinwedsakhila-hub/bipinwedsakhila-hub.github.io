BACKGROUND MUSIC
================

Put the song in this folder named exactly:  bgm.mp3

It starts when a guest taps "Open" on the first screen, and a small round
button at the bottom-left lets them pause it.

- To start the song from the middle (for example at 0:25), set
  musicStartAt: 25  in config.js.
- To turn music off completely, set  music: false  in config.js.
- Keep the file small (a 2-3 minute clip at 128 kbps is about 3 MB).
- Film songs are copyrighted, so use a track you are allowed to share publicly.

If bgm.mp3 is missing, the page simply stays silent and the button is hidden.
